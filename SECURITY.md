# Security Policy

## Reporting a vulnerability

Please do not open a public issue with vulnerability details, credentials, proof-of-concept exploits, or other information that could enable abuse.

When private vulnerability reporting is enabled for this repository, use GitHub's **Report a vulnerability** flow under **Security → Advisories** to send the report privately to the maintainers:

https://github.com/mynameistito/cf-gamedig/security/advisories/new

Include enough information to reproduce and assess the issue, such as the affected component, impact, reproduction steps, and any relevant logs with secrets removed.

If the private reporting flow is unavailable, do not publish exploitable details in a public issue. Contact the maintainer privately first to arrange an appropriate disclosure channel.
